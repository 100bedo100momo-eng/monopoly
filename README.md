# مونوبولي 🎲

لعبة مونوبولي عربية كاملة تعمل في المتصفح بدون أي تبعيات أو خادم خلفي: لوح من 40 خانة، شراء عقارات، إيجارات، منازل وفنادق، رهن، مزادات، بطاقات الفرصة وصندوق المجتمع، السجن، لاعبون بالكمبيوتر، وحفظ تلقائي للعبة.

## التشغيل محليًا

لا تحتاج إلى تثبيت أي حزم، فقط افتح `index.html` في المتصفح، أو شغّل خادمًا ثابتًا:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## البنية

| الملف | الوصف |
| --- | --- |
| `index.html` | هيكل الصفحة |
| `styles.css` | تصميم اللوح والواجهة (RTL، متجاوب مع الهاتف) |
| `app.js` | محرك اللعبة كامل: الأدوار، النرد، الاقتصاد، البطاقات، الذكاء الاصطناعي |

المشروع موقع ثابت (static)؛ على Vercel لا يلزم أمر بناء، وتُنشر الملفات كما هي من الجذر.

## طريقة اللعب

- ابدأ بـ 1,500 جنيه لكل لاعب، وارمِ النرد للتحرك؛ المرور على البداية يمنحك 200 جنيه.
- اشترِ العقار الذي تقف عليه أو اتركه للمزاد، وادفع الإيجار لصاحبه إن كان مملوكًا.
- اجمع مجموعة لونية كاملة لتبني المنازل (حتى فندق)، ويمكنك رهن العقارات عند الحاجة.
- الدوبل يمنح رمية إضافية، وثلاث دوبل متتالية تعني السجن.
- آخر لاعب يبقى بعد إفلاس الباقين يفوز. تُحفظ اللعبة في `localStorage` تلقائيًا.
